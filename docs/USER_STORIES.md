# 📖 User Stories — Sublima Decryptor

## Persona

Analista de mídia / pesquisador / forense digital que quer ler além do óbvio — com rigor e transparência.

## MVP

**US-01** Upload e análise de imagem → relatório em camadas  
**US-02** Visualizar evidências destacadas na imagem  
**US-03** Exportar relatório Markdown/PDF  
**US-04** Disclaimer explícito em interpretações especulativas

## Futuro

**US-05** Áudio/vídeo com timeline  
**US-06** Deep Scan multi-modelo  
**US-07** Histórico versionado  
**US-08** API pública  
**US-09** Modo local (privacidade)
